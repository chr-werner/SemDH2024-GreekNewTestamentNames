# NTtranscripts

This repository is containing a script to download all transcripts available from the 'International Greek New Testament Project' (IGNTP) at University of Birmingham and the 'New Testament Virtual Manuscript Room' (NTVMR) run by the 'Institute Für Neutestamentarische Forschung' (INTF) at Münster University.

The INTF transcriptions do get pulled via the [NTVMR API](https://ntvmr.uni-muenster.de/community/vmr/api/). 
The IGNTP data is downloaded via multiple direct links.
